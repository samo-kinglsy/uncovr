## UX principle

**Progressive disclosure:** Default screens should prioritize concise, scannable information. Show the essential answer or status first, and reveal descriptions, conditions, limitations, sources, and other details on demand where appropriate.

## Code comments

- Prefer self-explanatory code over excessive comments.
- Comment non-obvious technical decisions, workarounds, complex business logic, and important UNCOVR business rules.
- Explain why; do not simply restate what the code does.
